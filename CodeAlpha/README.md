## 🚀 Quick Start (Task 1: CGPA Calculator)

### 1. Compile the Source Code
```bash
# Using g++ on Windows / Linux / macOS
g++ -O2 -std=c++14 cgpa_calculator.cpp -o cgpa_calculator.exe
```

### 2. Run the Application
```bash
./cgpa_calculator.exe
```

## 🛠️ Features Implemented in Task 1
- **Dynamic Course Entry**: Input course code, course title, credit hours, and grade.
- **Multiple Grading Scales**: Supports 10.0 scale (UGC/AICTE), 4.0 scale (US/International), or direct numerical point entries.
- **Semester & CGPA Calculations**: Computes SGPA per semester and overall CGPA integrating historical semester data.
- **Formally Aligned Grade Sheet**: Tabular output formatting individual course results and cumulative standing.
- **File Export**: Exports full grade sheet and performance summary to `CGPA_Report.txt`.
- **Robust Input Handling**: Protects against invalid inputs, non-numbers, and out-of-range bounds.
